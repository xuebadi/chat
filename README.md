# 🎓 学霸帝Chat in English

> AI-powered English conversation practice for kids

基于 [hi-kid](https://github.com/xiaochong/hi-kid) 的桌面应用，让孩子们通过与 AI 对话练习英语口语。

## ✨ Features

- 🗣️ **Voice Conversation** - 语音对话，实时互动
- 🤖 **Local AI Models** - 本地 AI 模型，无需联网
- 🎮 **Fun Games** - 趣味游戏，边玩边学
- 🎨 **Kid-friendly UI** - 界面友好，适合儿童

## 📥 Download

**macOS**: [xueba-chat-english-0.1.0.dmg](https://github.com/xuebadi/chat/releases/download/v0.1.0/xueba-chat-english-0.1.0.dmg) (~129MB)

## 🚀 Quick Start

1. Download and install the DMG
2. Launch the app
3. Click the microphone button to start talking with AI!

## 📦 Tech Stack

- **Electron** + **React** + **TypeScript**
- **ASR**: Whisper (speech recognition)
- **TTS**: Piper (text-to-speech)
- **LLM**: Local AI conversation model
